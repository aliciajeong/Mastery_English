# Mastery English

React-based daily English study app for IELTS/PTE practice.

## Run locally

1. Install dependencies:

	npm install

2. Start dev server:

	npm start

3. Build for production:

	npm run build

## Project structure

- `src/App.js`: Main layout and tab composition
- `src/utils/appCore.js`: Shared data, helpers, analysis logic, and hooks
- `src/index.js`: React app bootstrap
- `public/index.html`: Root HTML shell
